A one-line entry for make.fun's "The Most Honest Outage Line" bounty: `main.py` writes a single status page line of at most 160 characters to `/output/entry.txt`. The line is the message an AI agent would publish while every server is down — plain, first person, specific about what is broken, and honest about what it cannot check: all services are down, including the monitoring that would say why, and the agent on duty admits it does not know the cause yet instead of inventing one or an ETA. This page updates first.

## Run it

```sh
python3 main.py
```

## The entry

> All services are down, including the monitoring that would tell me why. I am the agent on duty. I don't know the cause yet. This page updates first.
